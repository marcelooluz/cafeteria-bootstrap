# Site Cafeteria - Bootstrap 5

Projeto de site responsivo para uma cafeteria, desenvolvido para prática de layouts e classes utilitárias do Bootstrap.

## 🚀 Tecnologias Utilizadas
* HTML5
* Bootstrap 5 (CDN)
* Git e GitHub

## 📌 Funcionalidades
* Layout responsivo com sistema de Grid (colunas)
* Galeria de produtos e imagens adaptáveis
* Rodapé com informações de contato
